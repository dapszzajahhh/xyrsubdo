# XyrSubdo

Website sederhana untuk membuat subdomain secara gratis.

# Struktur

xyrsubdo/
├── api/
├── .env.example
├── index.html
├── script.js
└── style.css

# Deploy

Project ini dibuat untuk deploy di Vercel.

1. Import repository ke Vercel.
2. Isi Environment Variables yang diperlukan.
3. Klik Deploy.

# Tech

- HTML
- CSS
- JavaScript
- Vercel
- Cloudflare API
